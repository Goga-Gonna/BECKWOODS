# BECKWOODS.STORE

Luxury-streetwear / dark-premium интернет-магазин: Next.js 14 (App Router), TypeScript, Tailwind,
Framer Motion + GSAP, React Three Fiber, PostgreSQL + Prisma.
Концепция, карта страниц и дизайн-система — в [docs/CONCEPT.md](docs/CONCEPT.md).

> **Статус:** магазин работает в **демо-режиме**. Оплата не подключена (`PAYMENT_ENABLED=false`).
> Реальные продажи включать только после юридической проверки (возрастные ограничения,
> лицензирование, правила рекламы и доставки в вашей юрисдикции).

## Быстрый старт

Требуется Node.js 18.18+ и PostgreSQL 14+ (или Docker).

```bash
# 1. База данных (вариант с Docker)
docker compose up -d

# 2. Зависимости и окружение
npm install
cp .env.example .env        # затем задайте AUTH_SECRET и пароль администратора

# 3. Схема БД и тестовые данные
npm run db:push
npm run db:seed

# 4. Запуск
npm run dev                 # http://localhost:3000
```

Админ-панель: `/admin/login` (email и пароль из `.env`: `ADMIN_EMAIL`, `ADMIN_PASSWORD`).

## Что где редактировать

| Что | Где |
|---|---|
| Ссылки Telegram / Instagram, контакты, навигация, возраст | `config/site.ts` |
| Секреты, БД | `.env` (не коммитить) |
| Товары, цены, остатки, статусы заказов | `/admin` |
| Фото товаров | положите в `public/products/` и укажите `/products/имя.jpg` в админке |
| Палитра и шрифты | `tailwind.config.ts`, `src/app/globals.css` |

## Деплой

1. Managed PostgreSQL (Neon, Supabase, RDS) → `DATABASE_URL`.
2. `AUTH_SECRET` — `openssl rand -base64 48`; задайте сильный `ADMIN_PASSWORD`, выполните `npm run db:seed`.
3. `NEXT_PUBLIC_SITE_URL` — боевой домен (используется в SEO и sitemap).
4. Vercel / Node-сервер: `npm run build && npm start`. Включите HTTPS (cookie админа помечается `secure` в production).
5. Rate-limit хранится в памяти процесса. При нескольких инстансах замените на Redis (`src/lib/rate-limit.ts`).

## Безопасность

- Цены и остатки пересчитываются **на сервере**; клиентским ценам доверия нет.
- Все входные данные валидируются через zod (`src/lib/validation.ts`), ошибки — в едином формате.
- Админка: bcrypt + JWT в httpOnly/SameSite=Strict cookie; middleware закрывает `/admin` и `/api/admin`; логин ограничен по частоте.
- Остатки списываются атомарно в транзакции; при отмене заказа возвращаются на склад.
- Заголовки безопасности — `next.config.mjs`.

## Мобильная версия и облегчённый режим

- Отдельный мобильный UX: компактная шапка, нижняя tab-навигация, полноэкранное меню, корзина-шторка со свайпом, фильтры-шторка.
- Safe areas iPhone (`viewport-fit=cover`, `env(safe-area-inset-*)`), touch-зоны ≥ 44 px, поля ввода 16 px (без зума iOS), `overflow-x: clip`.
- Лёгкий режим включается автоматически (слабое устройство, Save-Data, 2G/3G, `prefers-reduced-motion`) или кнопкой в футере: вместо WebGL показывается статичный постер.
- На мобильных 3D-сцена упрощена (меньше полигонов, DPR ≤ 1.5, без сглаживания); рендер ставится на паузу, когда Hero вне экрана.
- Haptics — `navigator.vibrate` (Android; iOS Safari его не поддерживает).

## Известные ограничения

- В WebGL-сцене — хромовый тор-узел и орбитальные тела; **надпись BECKWOODS** — HTML-текст с 3D-наклоном за курсором и GSAP-анимацией, а не настоящий `Text3D` (он требует шрифт-файл и заметно тяжелее на мобильных).
- Управление 3D по гироскопу не реализовано (на iOS нужно отдельное разрешение); используется касание/указатель.
- Загрузка файлов изображений в админке не реализована: укажите путь `/products/…` (файл в `public/`) или URL.
- Автотесты не написаны.
